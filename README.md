# JET MEDIA — лендинг

Статический сайт без сборки и зависимостей: чистые HTML, CSS и JavaScript. Заявки уходят в Google Sheets и Telegram через Apps Script.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка, SEO- и OpenGraph-теги, JSON-LD |
| `styles.css` | Палитра и типографика брендбука, компоненты, адаптив |
| `script.js` | Переводы (RU/EN/TH), калькулятор, тарифы, отправка заявки |
| `logo.png` | Логотип из брендбука, фон удалён — корректно ложится на тёмные секции |
| `favicon.svg` | Иконка сайта: фирменная дуга и монограмма |
| `og-image.png` | Превью для соцсетей, 1200×630 |
| `Code.gs` | Код для Google Apps Script (в репозиторий можно не загружать) |

## Соответствие брендбуку v1.0

- Цвета: Jet Black `#080B17`, Jet Blue `#187BFF`, Electric Blue `#46C7FF`, White. Остальные оттенки — производные от них для границ, фона карточек и вторичного текста.
- Шрифты: Manrope (заголовки, кнопки, цифры) и Inter (основной текст). Для тайского добавлен Noto Sans Thai — в Manrope и Inter нет тайской графики.
- Логотип используется без изменений: без обводок, эффектов и перекраски. Единственная динамика — лёгкое затемнение при наведении в шапке.
- Фирменная дуга вынесена на первый экран как фоновый графический элемент — тот же жест, что и в знаке.

## Публикация на GitHub Pages

1. Загрузите файлы в корень ветки `main`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Замените `https://jetmedia.example/` в тегах `canonical`, `og:url` и JSON-LD на реальный адрес.

## Заявки: Google Sheets + Telegram

Схема: сайт → веб-приложение Apps Script → строка в таблице + сообщение в Telegram. Токен бота хранится в свойствах скрипта на стороне Google и в исходники сайта не попадает.

1. Создайте таблицу Google Sheets, например «JET MEDIA — заявки».
2. Расширения → Apps Script. Замените содержимое `Code.gs` на файл из этого проекта.
3. Впишите `BOT_TOKEN` и `CHAT_ID` в функцию `setup()` и запустите её один раз. Значения сохранятся в свойствах скрипта, из кода их можно удалить.
4. Запустите `testSend()` — в Telegram придёт тестовое сообщение, в таблице появится строка с шапкой.
5. Развернуть → Новое развёртывание → «Веб-приложение». Запуск: от моего имени. Доступ: у всех. Скопируйте URL вида `https://script.google.com/macros/s/AKfycb.../exec`.
6. Вставьте URL в `script.js`:

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
```

**После каждой правки `Code.gs`:** Развернуть → Управление развёртываниями → карандаш → Версия «Новая версия» → Развернуть. Без этого шага сайт продолжит обращаться к старой версии скрипта.

### Почему запрос уходит через GET

Веб-приложение Apps Script отвечает на POST редиректом на `script.googleusercontent.com`, и на этом редиректе браузер теряет preflight-запрос CORS — особенно внутри WebView Telegram. GET с параметрами в строке запроса preflight не требует, ответ читается, и пользователю показывается честный результат. Если GET по какой-то причине не прошёл, `script.js` пробует POST в режиме `no-cors`: ответ прочитать нельзя, но строка в таблице появится и сообщение уйдёт.

Вместе с контактами в Telegram приходит снимок калькулятора — сколько столиков, гостей и какой чек указал клиент. Менеджер видит ожидания ещё до звонка.

Если Apps Script не нужен, оставьте `APPS_SCRIPT_URL` незаполненным и укажите `BOT_TOKEN` и `CHAT_ID` в `script.js` — сайт обратится к Bot API напрямую. На статическом хостинге токен при этом виден любому посетителю, поэтому такой путь годится только для «одноразового» бота, пишущего в одну служебную группу.

## Настройка расчётов

`script.js`, блок «Бизнес-константы»:

```js
const UPLIFT  = { std: 0.10, prm: 0.15 };                      // прирост выручки
const PRICE   = { low:{std:10,prm:20}, high:{std:30,prm:60} }; // USD/устройство/мес
const USD_THB = 36;                                            // курс для окупаемости
```

Сейчас на сайте стоят цифры из ТЗ: Standard +10%, Premium +15%. В брошюре «Цифровой официант» заявлен более осторожный ориентир — «+6% и более» к среднему чеку. Если хотите, чтобы лендинг и брошюра говорили одно и то же, поставьте `{ std: 0.06, prm: 0.10 }`: пересчитаются и калькулятор, и план зала, и подписи в первом экране.

Окупаемость намеренно считается по цене высокого сезона — самый строгий сценарий, цифра не завышает ожидания.

## Языки

Все тексты в объекте `I18N` (`ru` / `en` / `th`), 155 ключей на язык. Чтобы добавить язык: скопируйте блок, переведите значения, добавьте кнопку в шапке и локаль в `LOCALES` — от неё зависит формат чисел.

```html
<button type="button" class="lang-btn" data-set-lang="zh">ZH</button>
```

Выбор языка запоминается, при первом визите берётся язык браузера.

## Что заменить перед запуском

- контакты в подвале (`@Nickbv`, `cto@dclwns.com`) — на рабочие;
- домен в `canonical`, `og:url` и JSON-LD;
- `og-image.png` — на кадр реального устройства на столе ресторана: карточка ссылки с фотографией собирает заметно больше переходов, чем текстовая.
